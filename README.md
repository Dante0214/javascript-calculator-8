# javascript-calculator-precourse

## 기능 목록

### 1. 입력 처리

- [ ] 사용자로부터 문자열 입력 받기
- [ ] 빈 문자열 입력 시 에러 반환

### 2. 구분자 처리

- [ ] 기본 구분자(쉼표, 콜론) 지원
- [ ] 커스텀 구분자 파싱 (`//`와 `\n` 사이의 문자)
- [ ] 여러 구분자가 혼합된 문자열 처리

### 3. 숫자 추출 및 계산

- [ ] 구분자를 기준으로 문자열 분리
- [ ] 분리된 문자열을 숫자로 변환
- [ ] 모든 숫자의 합 계산

### 4. 예외 처리

- [ ] 음수 입력 시 `[ERROR]` 메시지와 함께 Error 발생
- [ ] 숫자가 아닌 값 입력 시 Error 발생

### 5. 출력

- [ ] 계산 결과를 "결과 : {sum}" 형식으로 출력
